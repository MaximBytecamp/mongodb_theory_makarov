## Как собирается

Примеры модуля — только в `mongosh` (блоки без `data-lang`, видны при любом
языке); в `examples.py` и архивы модуль не входит.

```bash
python3 tools/m7/build.py   # тела tools/m7/body/7.N.html → temy/<папка>/index.html
python3 tools/m7/run.py     # загрузить данные главы, выполнить запросы, вписать код и вывод
python3 tools/m7/run.py show 7.4   # только посмотреть выводы
```

- Запросы — `tools/m7/queries.py`, в теле главы маркер `<!--Q 7.N имя--><!--/Q-->`.
- Команды одного запроса, разделённые пустой строкой, выполняются по очереди, и
  вывод каждой печатается: `mongosh --eval` показывает только последний результат.
- Нужен запущенный `course-mongo`. Повторный прогон даёт те же файлы байт в байт.
- Ничьи в сортировке задаются вторым ключом; `_id` вида ObjectId в вывод не попадает.
- Сегодняшняя дата в главах — 3 ноября 2026 года (напоминания, застрявшие заявки).
