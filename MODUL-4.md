## 1. Код примеров

Конвейер — список документов, как фильтр модуля 2. Поэтому код модуля 4
собирается генератором: стадии описываются один раз литералом Python в
`tools/chapters4.py`, функция `agg` превращает их в код на четырёх языках
(ключ `"plain"`, подсветка — `codeedit.highlight`).

| Язык | Конвейер | Запуск |
|---|---|---|
| Python | список словарей `pipeline = [...]` | `orders.aggregate(pipeline)` |
| Ruby | массив хешей | `orders.aggregate(pipeline)` |
| Go | `mongo.Pipeline{...}` — срез `bson.D` | `orders.Aggregate(ctx, pipeline)` |
| C++ | `mongocxx::pipeline` и его методы `match`, `sort`, `limit`, … | `orders.aggregate(pipeline)` |

У стадий без своего метода в mongocxx (`$set`, `$unset`, `$replaceWith`,
`$unionWith`) — `append_stage`.

Вывод документов — функция `show` из заготовки модуля: у каждого документа
выбранные поля в строку через « | », вложенные поля — через точку, в конце
«документов: N». Заказ целиком занимает десятки строк, поэтому до главы 4.2
документы показываются только этой функцией. Python и Ruby — `EXTRAS`, Go и C++ —
`TOP_EXTRAS` (одинаковые для всех глав модуля).

## 3. Главы

### 4.1 Конвейер агрегации: `$match`, `$sort`, `$limit` — **готова** (18.10.2026)
`temy/25-konveyer-match`. Порядок PLAN.md изменён: `$sort` и `$limit` вводятся
в 4.1 вместе с `$match`. Без них нельзя показать, что результат зависит от
порядка стадий, а смысл обеих стадий студент знает по `sort` и `limit` из
главы 1.6. Глава 4.5 остаётся за `$skip`, `$count`, `$sortByCount` и памятью
сортировки.

Примеры: одна стадия `$match` (13 заказов в пути, тот же результат у `find`) →
три стадии `$match` и счёт после каждой (120 → 69 → 22 → 5) → условия модуля 2
внутри `$match` (`$elemMatch`, `$in`, точечная нотация: 6 заказов) → `$sort`
и `$limit` (три самых дорогих заказа в пути) → порядок стадий (`$limit` 5 до
`$match` — 2 заказа, после — 5) → стадия с двумя операторами, ошибка 40323.

### 4.2 `$project`: форма ответа — **готова** (18.10.2026)
`temy/26-project`. Документы печатаются целиком (`agg_docs`), не через `show`.
Восемь примеров: включение (`_id` остаётся) → `"delivery.city": 1` (вложенность и
порядок полей документа) → новые имена `"$number"` → `$multiply`/`$subtract`
(double) → `$concat`, ошибка 16702, `$toString` → `$cond` 5/4 → смешивание 31254
и 31310 → `$project` до `$match` 0, после 13. Кадр 144.

### 4.3 `$addFields`, `$set`, `$unset` — **готова** (18.10.2026)
`temy/27-addfields-set-unset`. Восемь примеров: `card` при всех полях → то же в `$project` →
перезапись `price` (в коллекции 114990) → `delivery.fast` → новое поле в `$match`/`$sort`
(21 → 13 → 3) → `$set` как второе имя → `$unset` → `0` в `$addFields`. Кадр 145.
Исходник ошибочно разводит `$set` и `$addFields` — в книге сказано, что это одна стадия.
### 4.4 `$group` и аккумуляторы `$sum`, `$avg`, `$min`, `$max` — **готова** (18.10.2026)
`temy/28-group`. Восемь примеров: выручка по городам (69 → 5, Новосибирск 2 536 840) →
`_id: null` (69 / 8 532 630) → `$avg`/`$min`/`$max` и `$round` → ключ {город, способ} →
`$match` до `$group` (все заказы 4 371 990) → после (≥ 2 000 000: 2 города) → `$sum`
по строке 0, `$avg` null → ошибки 40234 и 15955. Кадр 146: порядок групп не задан.
### 4.5 `$skip`, `$count`, `$sortByCount`; память сортировки — **готова** (18.10.2026)
`temy/29-skip-count`. Семь примеров: страница 2 → `$limit`/`$skip` в двух порядках (5 и 8) →
`$count` 69 → `$count` после `$group` (2) → пустой поток (ничего) → `$sortByCount` = `$group`+`$sort` →
`explain`: `memLimit` 104857600 и `limitAmount 3`. Исходник ошибочно пишет, что `$sortByCount`
эффективнее, — в книге сказано, что это та же пара стадий. Кадр 147.
### 4.6 `$unwind`: массив становится документами — **готова** (26.10.2026)
`temy/30-unwind`. Девять примеров: заказ 2026-0002 → 3 документа → 120 заказов / 271 позиция →
категории (qty, `$multiply`) → `total` после `$unwind` 41 847 990 вместо 15 386 310 → `$match` до (154) /
после (67) / оба (67) → `includeArrayIndex` → `promo` 40/120 → пустые массивы через `$set`+`$cond` 228/248 →
топ-3 доставленных (iPhone 20). Пустых массивов в базах магазина нет — поэтому `promo` и `$set`. Кадр 154.
