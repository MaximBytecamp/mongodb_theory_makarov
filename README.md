# Справочник по MongoDB

Справочник к МДК.04.01 «Разработка и защита баз данных».
Автор — Макаров Максим Николаевич.

Книга-сайт: от первого документа до аналитической витрины. Каждый оператор
показан дважды — как он выглядит в оболочке и как тот же запрос пишется из
Python, — и подтверждён кадром MongoDB Compass на реальных данных.

## Устройство

```
index.html          обложка и содержание: модули, главы, практики
styles.css          типографика и наглядные блоки (документ, конвейер, кадры)
book.js             увеличение кадров Compass по клику, подсветка стадий
temy/NN-slug/       главы
praktiki/           практические работы и контрольные точки
shots/              кадры Compass, снятые на живом стенде
tools/              съёмка кадров: Playwright по CDP к Compass
PLAN.md             карта книги: модули, порядок тем, источники
AUTHORING.md        как пишется глава: блоки, примеры, кадры, чек-лист
MODUL-2.md          рабочий план модуля 2
MODUL-3.md          рабочий план текущего модуля
shared/             редакционная проверка текста
```

Сайт статический: открывается двойным кликом по `index.html`, публикуется как
есть, без сборки.

## Данные и практики

Все примеры выполнены на базах курса из репозитория
[mongodb-practice](https://github.com/MaximBytecamp/mongodb-practice): там же
стенд, готовые решения практических работ и скрипты самопроверки.

| База | Коллекции | Для чего |
|---|---|---|
| `shop` | products 21, orders 120, customers 20 | CRUD и агрегация |
| `hh` | resumes 9, vacancies 8, companies 8, interviews 60 | язык фильтров |
| `logs` | events 1200 | индексы и время |
| `org` | employees 15, categories 10 | иерархии |
| `sandbox` | products 21, warehouse 21 | песочница практик |

Данные детерминированные: числа в книге совпадают с тем, что получит студент.

## Пересъёмка кадров Compass

```bash
env -u ELECTRON_RUN_AS_NODE "/Applications/MongoDB Compass.app/Contents/MacOS/MongoDB Compass" \
  --ignore-additional-command-line-flags --remote-debugging-port=9222 &
node tools/shots-m1.mjs                 # все кадры модуля 1
node tools/shots-m1.mjs 06-find-filter  # один кадр
node tools/shots-m2.mjs                 # все кадры модуля 2
node tools/shots-m2.mjs 61-hh-gte       # один кадр
node tools/shots-m3.mjs                 # все кадры модуля 3 (флаги запуска — в шапке скрипта)
```

Кадры снимаются на живом стенде: что на кадре — то и в базе.
